# 🎉 Undangan Digital

Undangan Digital adalah website undangan pernikahan online yang responsif, interaktif, dan mudah disebarkan. Website ini mempermudah pengantin untuk menyampaikan informasi acara secara elegan dan praktis kepada tamu.

## 🚀 Fitur
- Countdown timer ke hari H.
- Detail acara dengan peta lokasi Google Maps.
- Galeri foto interaktif dengan slider.
- Buku tamu dengan data tersimpan di Firebase.
- Musik latar otomatis yang dapat diaktifkan/di-nonaktifkan.
- Desain responsif dengan animasi smooth.

## 🛠 Tech Stack
- **Frontend**: HTML, CSS, JavaScript, Bootstrap, Swiper.js, AOS.
- **Backend**: Firebase Realtime Database.
- **Hosting**: Vercel.


## 🚚 Deployment
Proyek ini dihosting di Vercel Hosting, memungkinkan akses cepat dengan domain kustom.

## 📝 Cara Penggunaan
1. Clone repositori ini:
   ```bash
   git clone https://github.com/Syaekhul/undangan-digital.git
   Edit konten di index.html sesuai kebutuhan (nama pengantin, detail acara, dll.)
   Deploy ke Firebase Hosting atau server lain sesuai preferensi.
   ```
